Política de Privacidade - Gestão Gráfica

Última atualização: 27 de novembro de 2026.

O Gestão Gráfica é um aplicativo de gestão de vendas, orçamentos e pedidos para gráficas. Esta página explica como ele trata os seus dados.

Quais dados o aplicativo usa

Os dados que você cadastra (clientes, produtos, vendas, orçamentos, pedidos, artes e configurações) ficam armazenados no seu próprio navegador, neste aparelho.

Se você escolher entrar com o Google, o aplicativo acessa apenas:

  • o seu endereço de e-mail, exibido na tela para mostrar qual conta está conectada;
  • uma pasta oculta e exclusiva do aplicativo no seu Google Drive (escopo drive.appdata), onde é guardado o arquivo de backup.

O aplicativo não acessa os seus outros arquivos do Drive, nem seus e-mails, contatos ou qualquer outro dado da conta Google.

Como os dados são usados

O e-mail e o backup são usados somente para o recurso de backup e restauração do aplicativo. Os dados não são vendidos, compartilhados, usados para publicidade nem enviados a servidores do desenvolvedor. O uso das informações obtidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Onde os dados ficam

Os dados ficam no seu navegador e, se você ativar o backup, na sua conta do Google Drive. O desenvolvedor não tem acesso a eles.

Como apagar os seus dados

  • No aplicativo, em Configurações > Dados e backup, use Apagar backup da conta para remover o backup do Drive, ou Limpar neste aparelho para apagar os dados do aparelho.
  • Para revogar o acesso do aplicativo à sua conta, acesse myaccount.google.com/permissions e remova o Gestão Gráfica.
